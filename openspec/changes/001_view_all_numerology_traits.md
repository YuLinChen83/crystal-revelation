# OpenSpec Change: 查看所有靈數特質功能

## 1. 變更說明
在「生命靈數測算」頁面中，當用戶已經進行了生日測算並顯示結果時，在「測算能量」按鈕下方顯示一個「查看所有靈數特質」的文字按鈕。點擊後會開啟一個彈窗（Modal），呈現 `numerologyData` 中所有生命靈數（0-9）的詳細文字內容。

## 2. 規格細節

### 2.1 觸發入口
* **顯示時機**：只有在 `result` 狀態不為空（即已算出主命數與缺數）時顯示。
* **按鈕位置**：位於測算表單下方（「測算能量」按鈕的下方）。
* **樣式**：文字按鈕，呈現微底線或懸停變色（hover）的精緻質感，字體與網站主體風格一致，置中對齊。

### 2.2 彈窗設計
* **背景**：半透明毛玻璃或黑色半透明遮罩背景（`rgba(0, 0, 0, 0.5)`），支援點擊背景關閉彈窗。
* **容器**：最大寬度 680px（或符合響應式尺寸），自帶陰影與細邊框，並限制最大高度（例 `maxHeight: '80vh'`），當內容溢出時支援流暢滾動（`overflowY: 'auto'`）。
* **關閉按鈕**：右上角提供 "✕" 關閉圖示，亦可透過 ESC 鍵或點擊遮罩關閉。
* **內容展示**：
  * 排版清晰地列出 0 到 9 號生命靈數的名稱、氛圍、肯定語、命定水晶說明與缺數水晶說明。
  * 使用優雅的邊框或小卡片區隔各個靈數，以利閱讀。

## 3. 程式異動範圍
* **`src/components/NumerologyCalculator.tsx`**：
  * 新增彈窗開啟狀態 `const [showTraitsModal, setShowTraitsModal] = useState(false);`
  * 在表單後方新增「查看所有靈數特質」的點擊按鈕。
  * 新增一個彈窗組件或內嵌 JSX 渲染彈窗，列出 `numerologyData.life_path_data` 的所有項。
  * 調整樣式表以支援彈窗之磨砂玻璃、滾動條、關閉按鈕與排版。
